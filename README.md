# 同济大学本科生学科竞赛指南（2026版）

一个纯静态的学科竞赛查询页面，基于《同济大学本科生学科竞赛目录（2026版）》整理，支持搜索、筛选、个人/团体赛标识，并附带获奖比例、难度评级、推荐度和参赛建议。

## ✨ 功能特性

- **搜索**：按竞赛名称、学院、关键词快速查找
- **筛选**：按赛事等级（A+ / A / B / C）筛选
- **个人/团体标识**：
  - ⭐ 金色边框 = 个人赛友好
  - 🟣 紫色边框 = 团体赛
- **竞赛指标**：每项竞赛展示获奖比例、难度评级、推荐度
- **参赛建议**：针对每项竞赛给出备赛和组队建议
- **统计面板**：实时显示竞赛总数、个人友好数、团体赛数、当前显示数
- **响应式布局**：适配电脑和手机
